# Code of Conduct

RiftLinux adopts the **Contributor Covenant, version 2.1**, as its code of conduct. It applies to everyone in the
project's spaces: issues, pull requests, discussions, and any other channel that belongs to the project.

- Text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Summary: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct_2.1_summary/>

The text at that address is the one that applies; this repository keeps no copy of its own.

## Scope

It applies to:

- the project's issue tracker, pull requests, discussions and other project channels;
- public communication where someone speaks for the project;
- direct communication between people acting in their project role.

It does not apply to unrelated personal projects, or to forks that no longer work together with this repository.

## Reporting

To report behaviour the Contributor Covenant describes as unacceptable, e-mail the maintainer at
<aix.m@outlook.com> with the subject starting **`[RiftLinux Conduct]`**. Please include:

- what happened, in your own words;
- where it happened (which issue, pull request or channel, roughly when);
- links to anything public that is relevant;
- whether your name may be used while the report is handled, or it should stay anonymous as far as possible.

## Enforcement

The maintainer reviews reports and decides on one of: no action (with the reason), a private conversation, a public
correction, or a temporary or permanent ban from the project's spaces, following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
The reporter's identity is kept confidential unless they agree otherwise. Good-faith reporters are never penalised
for reporting. A decision can be appealed by e-mail to the same address; if the report concerns the maintainer, say
so, and it will be reviewed by someone uninvolved where possible.
